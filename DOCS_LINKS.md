# Host documentation links

Official plugin/extension documentation for each host, as cited when v1.0.0 was built and re-checked for the
published repos. The kit used to carry local snapshots of these pages; they were removed because the pages are
third-party documentation without a clear redistribution license. Always read the live page: formats drift.

`python3 tools/check_kit.py` checks that every link here resolves.
